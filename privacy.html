プライバシーポリシー

TaskBoard-Notify（開発・運営：msmsrep）／最終更新日：2026年8月12日

TaskBoard-Notify（以下「本アプリ」）は、Windows 用の予定・タスク通知アプリです。 利用者が指定した接続先から予定・タスクの一覧を定期的に取得し、開始時刻の前にトースト通知でお知らせします。

本アプリは、開発者が運営するサーバーを一切持ちません。 利用者の情報が開発者へ送られることはなく、通信先は利用者自身が設定した接続先だけです。

1. 開発者が収集する情報

ありません。本アプリは次のいずれも行いません。

  • ユーザー登録、アカウント作成（氏名・メールアドレス等の入力を求めることはありません）
  • 利用状況の解析、アクセス解析、広告識別子の取得
  • クラッシュレポート・ログの自動送信
  • 取得した予定・タスクの内容、資格情報、設定内容の開発者への送信

2. 端末内に保存される情報

本アプリは、動作に必要な次の情報を利用者の端末内にのみ保存します。 いずれも外部へは送信されません。

保存されるもの内容保存形式
sources.json 接続先の定義（接続先のURL、取得間隔、解析方法など） 平文のJSON
sources.previous.json 定義ファイルを取り込みで置き換える直前の内容（元に戻すための控え） 平文のJSON
credentials.json 接続先の認証に使うユーザー名・パスワード・APIキー（利用者が設定画面で登録した場合のみ） パスワードとAPIキーは Windows の DPAPI（CurrentUser）で暗号化。同じ Windows ユーザーのみ復号でき、別ユーザー・別PCへコピーしても復号できません

保存先は次のとおりです。

  • ストア版・MSIX版：%LOCALAPPDATA%\Packages\{パッケージ名}\LocalState
  • exe版（インストーラーを使わない配布）：%LOCALAPPDATA%\TaskBoard-Notify

実際の保存先は、アプリの設定画面から確認できます。

接続先から取得した予定・タスクの内容（件名・時刻・リンク先URL）は、通知済みかどうかの判定のために アプリ実行中のメモリ上でのみ保持します。ファイルには書き出さず、アプリを終了すると失われます。

3. 通信について

本アプリの主な機能は外部サーバーからのデータ取得であるため、通信を行います。 ただし、通信先は利用者が定義ファイル（sources.json）に記載した接続先に限られます。 アプリにあらかじめ組み込まれた接続先はなく、初期状態では接続先0件のため通信は発生しません。

送信される内容

  • 定義ファイルに記載されたURLへのHTTPリクエスト（設定した取得間隔ごとに自動で実行されます）
  • 接続先がログインを必要とする場合：登録したユーザー名・パスワードを、定義ファイルに記載されたログインURLへ送信します
  • 接続先がAPIキーを必要とする場合：登録したAPIキーを、定義ファイルに記載された形式（リクエストヘッダーまたは本文）で送信します

これらの送信先・送信内容・送信タイミングは、すべて利用者が定義ファイルで指定したものです。 開発者はこれらの通信内容を受け取ることも、参照することもできません。

通信の安全性について

通信の暗号化は、利用者が指定したURLのスキームに従います。 https:// を指定した場合は暗号化されますが、http:// を指定した場合は暗号化されません。 資格情報を扱う接続先には https:// の利用をおすすめします。

動作確認用サイトについて

設定画面の「テスト用の設定を入れる」を使用した場合、接続先として本サイト （https://msmsrep.github.io/TaskBoard-Notify）が追加されます。 配信しているのは動作確認用の固定データのみで、認証は不要です。 本サイトは GitHub Pages（GitHub, Inc.）でホストされており、アクセスに伴う技術的な記録の取り扱いは 同社のポリシーに従います。開発者側で閲覧者を識別する仕組みは設置していません。

4. 第三者提供

本アプリが利用者のデータを第三者へ販売・共有・提供することはありません。 法令に基づく開示請求に応じる場合を含め、開発者は利用者のデータを保有していないため、提供できるデータがありません。

5. データの削除方法

ストア版・MSIX版

アプリをアンインストールすると、LocalState フォルダごと削除されます。 上記の保存データもあわせて削除されます。

exe版

アプリのファイルを削除しても、%LOCALAPPDATA%\TaskBoard-Notify フォルダは残ります。 完全に削除する場合は、このフォルダを手動で削除してください。

資格情報だけを削除する場合

設定画面の各接続先から、登録済みの資格情報を個別に削除できます。 アプリを使い続けたまま、パスワード・APIキーだけを消すことができます。
